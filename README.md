# Alternative_CA
TaxEase India is a privacy-first, intelligent tax filing assistant &amp; calculator for AY 2026-27 (FY 2025-26). It parses Form 16 &amp; AIS, provides instant Old vs New regime comparison, optimizes deductions (80C, 80D, HRA, NPS), reconciles TDS, and generates ready-to-file ITR-1/ITR-2 schedule summaries with complete data security.
